# Delhivery Delivery Analysis And Strategy Building

This repository contains my raw data analysis notebook exploring the Delhivery dataset.

## How to Run This Project
1. Clone this repository.
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Open the notebook:
   ```bash
   jupyter notebook Delhivery_Case_Study.ipynb
   ```
